# Investigation

The goal is an answer, not a code change. Do not edit product code.

1. **State the question** and what would count as an answer.
2. **Gather evidence** from the code, logs, git history, and by running the thing. Note where each fact came from.
3. **Separate what you saw from what you infer.** Mark guesses as guesses.
4. **Answer first**, then the evidence, then open questions. If a fix is warranted, hand off to `playbooks/bug-fix.md` or `playbooks/feature.md` rather than starting it.

**Reply:** the answer, the evidence with file paths or commands, and what you could not verify.
